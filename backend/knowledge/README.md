# Fill-in knowledge base

These Markdown files are the only owner facts supplied to the answering engine. Replace every
`TODO(owner)` with reviewed information you are comfortable publishing.

- Keep the YAML front matter at the top of each file.
- Use `##` headings to split information into focused sections.
- Keep the first three FAQ headings synchronized with the frontend suggestion chips.
- Put dated resume files in `resume/` using `resume_dd_mm_yyyy.pdf`.
- Never add secrets, private addresses, health information or facts the assistant should not say.

Production startup deliberately fails while any `TODO(owner)` remains.
